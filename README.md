# Shopping Cart 🛒

A simple shopping cart built with **HTML, CSS, and Vanilla JavaScript**.

## ✨ Features

* Fetch products from an API and show them
* Plus or minus products quantity
* Save in local storage
* Show in shopping cart
* Search between products
* Calculate prices
* Product loading state
* Error handling
* Modern dark-themed UI

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Fetch API
